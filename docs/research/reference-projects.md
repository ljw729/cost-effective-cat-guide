# Phase 1：参考项目研究笔记

只记录**工程思想和知识组织方法**。本项目不复制任何参考项目的内容、文字、视觉或分类。

## 《高性价比人生指南》（eternity4719/HowToLiveBetter）

观察到的值得借鉴的做法（2026-11 查看仓库结构与 README）：

- 每条建议写明“花掉什么、换回什么、证据有多硬、原始出处”，颗粒度是**一条可执行的建议**，不是一篇文章。
- 明确声明“这是备选单，不是任务清单”，降低读者焦虑。
- 有公开的**核实记录**目录，把来源核对过程留痕。
- 一份内容，多种输出：网页检索、PDF、EPUB、离线单文件 HTML、AI skill。
- 内容与代码使用不同的许可证。

本项目的不同之处（独立设计）：

| 方面 | 本项目 |
|---|---|
| 领域风险 | 动物医疗：增加 `medical_review_required`、`review_status`、紧急条目不评分、禁止写剂量 |
| 数据 | 结构化 YAML + JSON Schema + 来源注册表（来源只登记一次），而不是 Markdown 正文 |
| 证据 | 区分“来源存在”和“来源支持结论”；记录读到全文还是摘要 |
| 性价比 | 透明公式：收益 × 证据置信度 − 成本 − 伤害，带封顶规则，代码与文档同步、测试锁定 |
| 质量控制 | 自动校验、查重、过期检测、Crossref 核对，全部进 CI |

## 其他借鉴的组织方法

- **临床指南的结构**（AAFP/ISFM、AAHA）：把建议按生命阶段和环境需求组织；“五大支柱”这类框架便于普通人记忆。本项目在行为分类中引用这一框架，但条目以“主人能做什么”为单位重新组织。
- **循证医学的证据分级思想**：证据等级描述“这条结论有多可靠”，与来源的机构权威性分开。
