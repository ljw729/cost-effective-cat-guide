# 预算优先级模型

> 不给固定金额：物价、地区、猫的情况差别太大。这里回答的是 **钱应该按什么顺序花**。

## 五层优先级

| 层级 | 内容 | 原则 |
|---|---|---|
| **1. 安全 + 基础营养 + 必要医疗** | 封窗、清除有毒物、营养完整的主食、核心疫苗、急症就医 | **不能省**。预算再紧也先保证这一层。急症时医疗优先于一切成本考虑。 |
| **2. 卫生** | 足够数量的猫砂盆和猫砂、水碗、清洁 | 可以买便宜的，但数量和频率不能省。 |
| **3. 环境** | 躲藏处、抓挠处、高处、玩具、互动时间 | 大部分可以免费或自制（纸箱、逗猫棒）。 |
| **4. 便利设备** | 自动喂食器、饮水机、自动猫砂盆、摄像头 | 买之前问：它替代了什么？没有它会出问题吗？ |
| **5. 非必要消费** | 保健品、网红用品、高价猫窝 | 先看证据；“暂无充分证据”时，不买通常是合理的。 |

## 不同预算怎么用

- **极低预算**：只做第 1、2 层，第 3 层全部自制。这已经覆盖了大多数真正重要的事。
- **基础预算**：在此基础上留出**急诊备用金**，这比任何用品都重要。
- **舒适预算**：按老年猫、多猫等具体需求增加体检项目和资源数量。
- **高预算**：钱多不等于要多买；把钱花在兽医时间（更全面的检查、行为咨询）通常比买设备更值得。

## 从指南条目看

截至 v0.1 的条目中，性价比 S / A 的大多是 **几乎免费的“不要做”和安全措施**（不放百合、不用狗用驱虫药、不照网上配方自制猫饭、封窗、芯片），
而性价比 D 的是 **需要花钱的设备**（饮水机、洁牙零食）。这与本模型一致：**最重要的事情往往最便宜。**
